# Project Instructions

Keep work local to the current repository and the user request.

- Read only files needed for the task.
- Make the smallest change that solves the request.
- Run focused checks when useful and report what was actually verified.
- Do not create or update memory, journals, task systems, hooks, agents, or automation unless explicitly asked.
- Treat `.trellis/`, `.claude/`, and legacy process files as inactive unless the task explicitly concerns them.
- Never expose or commit secrets, `.env` values, complete chats, or raw logs.
